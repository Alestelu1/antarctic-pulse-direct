# Project Identity

Antarctic Pulse / Pulso Antártico is a documentary and editorial media project focused on:

- Antarctica
- Patagonia
- Southern Ocean routes
- Polar science
- Maritime geography
- Antarctic access
- Southern Chile
- Puerto Williams
- Punta Arenas
- Southern infrastructure
- Polar logistics

The project aims to document and explain the southern frontier through geography, science, routes, maps and strategic southern narratives.

The tone must remain:
- professional
- documentary
- geographic
- scientific
- editorial
- minimalist
- internationally oriented

Avoid sensationalism and propaganda aesthetics.

---

# Editorial Perspective

The project operates from a Chilean southern perspective while maintaining international documentary standards.

Content should emphasize:
- geography
- logistics
- science
- maritime routes
- infrastructure
- maps
- southern territories

Avoid:
- aggressive nationalism
- conspiracy framing
- low credibility sources
- tourist influencer aesthetics
- exaggerated patriotic visuals
